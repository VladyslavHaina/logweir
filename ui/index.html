Logweir

A Kubernetes API client. It runs with the authority of the kubeconfig that started the proxy serving it, and it holds no credential of its own.

Served by kubectl proxy, which attaches the viewer's own kubeconfig credential to every request it forwards. See ui/README.md for what that costs and how to narrow it.
